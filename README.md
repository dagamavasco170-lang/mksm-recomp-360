# MKSM Recomp

An experimental native-PC recompilation project for **Mortal Kombat: Shaolin Monks, NTSC-U retail (SLUS_210.87)**, maintained by [OGmidway](https://github.com/OGmidway), built on [PS2Recomp](https://github.com/ran-j/PS2Recomp).

**Not a playable release yet.** Menus, character/difficulty selection and the opening movie reach scene drawing. First-stage graphics are badly corrupted. The intended Goro's Lair introduction and controllable gameplay remain unverified. Windows is the tested host; portable C++ and Linux/macOS support remain project goals, not verified releases.

## Experimental Xbox 360 RGH/JTAG port

This fork is preparing a native PowerPC/Xenos build using [xSDK](https://github.com/xenosworks/xsdk). The initial C++20 smoke-title source is in `port/xbox360/`; it validates XEX packaging, runtime features, 720p GPU presentation and controller input before the game runtime is integrated.

**There is no playable Xbox 360 game build yet.** On code commit `b871e08`, the portable EE/controller/SIMD workflow [45305606450](https://github.com/dagamavasco170-lang/mksm-recomp-360/actions/runs/45305606450) passed, including the new MMI dispatcher regression test; the smoke XEX build [45305606408](https://github.com/dagamavasco170-lang/mksm-recomp-360/actions/runs/45305606408) also passed. These are CI results, not a new console test. The latest physical-console evidence is run #80, which records startup, ABI/memory/SIMD probes, display and controller behavior, 439 frames and clean exit. The smoke title does not contain the MKSM game runtime or PS2 GS renderer, and the guest-memory helper is not integrated into the runtime.

Engineering references are [Tenkaichi3Decomp](https://github.com/z3xox/Tenkaichi3Decomp) and [BT3XBx](https://github.com/Lucas-Tito/bt3xbx) for PS2-to-Xbox port structure, [Laika64](https://github.com/ErickaguirreD/Laika64) for Xenon PowerPC dynarec/code-cache lessons, and [Ibara360](https://github.com/PaulAtreides67/ibara360) for another xSDK-based native title. Their architectures and licenses differ; reuse boundaries are documented in [REFERENCES.md](docs/xbox360/REFERENCES.md).


### Xbox 360 guest CPU bootstrap status

The `port/xbox360` directory also contains an experimental PS2 Emotion Engine (R5900) instruction-dispatch prototype with scalar arithmetic, selected immediate and load/store operations, initial branch/jump and delay-slot handling, and a small dispatcher-connected MMI subset (`PMADDH`, `PMFHI`, `PMFLO`, `PMTHI`, `PMTLO`). The MMI-dispatcher code in commit `b871e08` passed the portable EE, controller and SIMD test workflows. Branches inside delay slots, exception/interrupt behavior, full 64-bit EE semantics, the rest of MMI, COP0/COP1/VU execution, and integration with the game runtime are not implemented. This is groundwork—not a game port or compatibility claim.

See the [port roadmap](docs/xbox360/PORT_PLAN.md), [source audit](docs/xbox360/SOURCE_AUDIT.md), [SIMD compatibility audit](docs/xbox360/SIMD_COMPATIBILITY.md), [SDK evaluation](docs/xbox360/SDK_EVALUATION.md) and [build/test instructions](port/xbox360/README.md).

## What is included

The modified recompiler, analyzer, C++ runtime, IOP services, runtime debugger, Python investigation tools, focused tests, Ghidra scripts, retail function boundaries and reviewed/candidate symbol metadata. Local generated code, game media and memory dumps are regenerated by contributors.

No ISO, ELF, extracted game assets, prototype executable, proprietary SDK, disassembly dump, memory card, or generated game translation is distributed here. Use your own game copy. Do not attach those files to issues or PRs.

## Quick start

```sh
git clone https://github.com/OGmidway/mksm-recomp.git
cd mksm-recomp
python tools/project.py check
```

Install the prerequisites and place your extracted retail disc in `MortalKombatShaolinMonks/`, then:

```sh
python tools/project.py all --jobs 2
python tools/project.py run
```

This is a substantial source build. Read [BUILDING.md](docs/BUILDING.md) first. The prototype is optional and is not required for retail generation.
