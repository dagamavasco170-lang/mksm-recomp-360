# MKSM Recomp

An experimental native-PC recompilation project for **Mortal Kombat: Shaolin Monks, NTSC-U retail (SLUS_210.87)**, maintained by [OGmidway](https://github.com/OGmidway), built on [PS2Recomp](https://github.com/ran-j/PS2Recomp).

**Not a playable release yet.** Menus, character/difficulty selection and the opening movie reach scene drawing. First-stage graphics are badly corrupted. The intended Goro's Lair introduction and controllable gameplay remain unverified. Windows is the tested host; portable C++ and Linux/macOS support remain project goals, not verified releases.

## Experimental Xbox 360 RGH/JTAG port

This fork is preparing a native PowerPC/Xenos build using [xSDK](https://github.com/xenosworks/xsdk), pinned to the open xSDK toolchain. The isolated target lives in `port/xbox360/`.

**There is no playable Xbox 360 game build yet.** The last fully validated baseline is commit `dc8a0e4`: portable controller/EE/SIMD tests passed ([run 45604243741](https://github.com/dagamavasco170-lang/mksm-recomp-360/actions/runs/45604243741)), generated PS2Recomp code passed both desktop and Xenon-ABI host execution ([run 45604244051](https://github.com/dagamavasco170-lang/mksm-recomp-360/actions/runs/45604244051)), and console/headless XEX builds plus Xenia headless execution passed ([run 45604243799](https://github.com/dagamavasco170-lang/mksm-recomp-360/actions/runs/45604243799)). The Xenia trace explicitly skipped graphics because Canary has no xSDK display-controller emulation; this was not a physical-console run.

The current `xbox360/bootstrap` revision adds a bounded dispatcher implementation for PS2 EE `LQ`/`SQ`: full 128-bit transfers through the wrapped-RAM helper, silent 16-byte address alignment, and the architectural GPR-zero behavior. Decoder/executor regressions pass in [portable test run 45608745004](https://github.com/dagamavasco170-lang/mksm-recomp-360/actions/runs/45608745004), and generated-code parity remains green in [run 45608744808](https://github.com/dagamavasco170-lang/mksm-recomp-360/actions/runs/45608744808). The rebuilt XEX/Xenia validation is [run 45608744931](https://github.com/dagamavasco170-lang/mksm-recomp-360/actions/runs/45608744931), which is still queued at the time of this update. The last fully validated Xenia trace is therefore the `dc8a0e4` baseline, not yet the new LQ/SQ revision.

Engineering references are [Tenkaichi3Decomp](https://github.com/z3xox/Tenkaichi3Decomp) and [BT3XBx](https://github.com/Lucas-Tito/bt3xbx) for PS2-to-Xbox port structure, [Laika64](https://github.com/ErickaguirreD/Laika64) for Xenon PowerPC dynarec/code-cache lessons, and [Ibara360](https://github.com/PaulAtreides67/ibara360) for another xSDK-based native title. Their architectures and licenses differ; reuse boundaries are documented in [REFERENCES.md](docs/xbox360/REFERENCES.md).


### Xbox 360 guest CPU bootstrap status

The `port/xbox360` directory contains an experimental R5900 instruction-dispatch prototype with selected scalar arithmetic, immediate, branch/delay-slot, load/store and MMI operations. Its deterministic 17-instruction trace covers arithmetic, RAM, a taken branch and delay slot, and HI/LO/MMI state. The dispatcher now also has host-tested `LQ`/`SQ` support over a bounded, power-of-two wrapped-RAM span. This is not a full EE: exceptions, complete 64-bit semantics, general TLB/COP0, COP1/VU execution, the full DMAC/MMIO bus and integration with retail generated game code remain incomplete or unverified.

See the [port roadmap](docs/xbox360/PORT_PLAN.md), [source audit](docs/xbox360/SOURCE_AUDIT.md), [SIMD compatibility audit](docs/xbox360/SIMD_COMPATIBILITY.md), [SDK evaluation](docs/xbox360/SDK_EVALUATION.md) and [build/test instructions](port/xbox360/README.md).
## What is included

The modified recompiler, analyzer, C++ runtime, IOP services, runtime debugger, Python investigation tools, focused tests, Ghidra scripts, retail function boundaries and reviewed/candidate symbol metadata. Local generated code, game media and memory dumps are regenerated by contributors.

No ISO, ELF, extracted game assets, prototype executable, proprietary SDK, disassembly dump, memory card, or generated game translation is distributed here. Use your own game copy. Do not attach those files to issues or PRs.

## Quick start

```sh
git clone https://github.com/OGmidway/mksm-recomp.git
cd mksm-recomp
python tools/project.py check
```

Install the prerequisites and place your extracted retail disc in `MortalKombatShaolinMonks/`, then:

```sh
python tools/project.py all --jobs 2
python tools/project.py run
```

This is a substantial source build. Read [BUILDING.md](docs/BUILDING.md) first. The prototype is optional and is not required for retail generation.
